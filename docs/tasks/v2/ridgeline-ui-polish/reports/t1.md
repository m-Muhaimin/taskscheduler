## Notes for Wave B consumers

- `Card` does NOT include the settings `[&>*+*]:border-t` behavior in its own className — dividers live on `DividerRow` (`border-t border-border first:border-t-0`), so a Card composed only of `DividerRow` children matches SectionCard exactly. Consumers mixing bare children should add the `*+*` variant via `className` if they need dividers.
- The global reduced-motion kill-switch (`*::after { animation-duration: 0.001ms !important }`) does not fight the shimmer exclusion: `.skeleton::after` is higher specificity than `*::after` and uses `animation: none`, so under reduced motion the shimmer is fully removed (opacity 0).

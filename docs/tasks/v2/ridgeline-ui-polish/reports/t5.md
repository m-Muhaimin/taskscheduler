## Deviations

1. **`DividerRow` not used for the footer; `Card` only.** Rationale: the auth Card is a *padded* card (`p-6 md:p-8` per the brief), and `DividerRow`'s fixed row paddings (`px-5 py-4`) would double-indent and add 16px vertical padding. Overriding them via plain class concatenation is unreliable — the repo has no `cn()`/`twMerge` helper, and Tailwind resolves the `px-5` vs `px-0` / `py-4` vs `pt-6` conflicts by stylesheet order, not class order. The brief also mandates keeping today's footer spacing (`mt-8 pt-6 border-t border-border`) verbatim, which the kept inline block preserves exactly. This matches T1's documented usage contract ("consumers mixing bare children should add the `*+*` variant… dividers live on the child") — the footer is the DividerRow *pattern* (top-divider row inside the card) implemented as a bare child of the padded Card. If strict `DividerRow` usage is required, the separate follow-up is a merge helper (or a `DividerRow` padding variant) — not part of this task.
2. No other deviations. Build flakiness during the wave is recorded above for the integration-build owner.
